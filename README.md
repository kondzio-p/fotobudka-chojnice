# Fotobudka Chojnice

Strona firmy wynajmującej fotobudki 360, fotolustro i efekty specjalne na wesela i eventy. Projekt i wykonanie dla klienta, strona działa produkcyjnie.

Strona: https://fotobudka-chojnice.pl

## Co jest w środku

- galeria filmów z posterami i przyciskiem play/pause, żeby strona szybko ładowała się na telefonie
- karuzela i lightbox zdjęć, FAQ
- osobne podstrony usług (fotobudka 360, fotolustro, ciężki dym, fontanny iskier, neony LED) pod SEO
- canonical, Open Graph, sitemap i robots.txt

## Technologie

HTML, CSS, JavaScript, Bootstrap. Wcześniej hostowana na własnym VPS (Apache).
